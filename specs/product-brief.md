# 宠你奇怪 — 产品需求文档

## 产品定位

**产品名称**：宠你奇怪（Weird Pet）
**平台**：移动端 Web App（手机浏览器 / PWA）
**目标用户**：Z世代城市年轻人（18-26岁），有强烈情绪表达需求，认同躺平/摆烂/发疯文化，日常使用微信/小红书传播表情包
**核心价值**：不是传统宠物养成，而是一面「情绪镜子」——3D丑萌宠物实时反映用户的社会情绪状态，并可将情绪瞬间导出为表情贴纸传播到社交平台
**差异化**：丑萌而非可爱、情绪驱动而非养成驱动、可传播的贴纸导出是核心闭环

---

## 核心功能列表

### F1 — 3D丑萌宠物主屏展示
- 全屏展示一只程序化几何体拼装的丑萌宠物（主体：不规则软体形态，夸张比例）
- 技术实现：React Three Fiber + 程序化几何体（SphereGeometry + CapsuleGeometry 变形拼装）
- 支持外部 GLTF 模型替换：用户可提供开源 .glb 文件 URL，通过 `useGLTF` 加载覆盖默认模型
- Bloom 荧光轮廓后处理 + 轻微 ChromaticAberration，营造酸性发光质感
- 宠物整体占屏高78%，居中展示

### F2 — 情绪状态系统（5种情绪）
- 情绪类型：躺平 / 发疯 / 摆烂 / 破防 / 无语
- 顶部状态标签实时显示当前情绪（如「当前状态：摆烂中」）
- 底部 HUD 5个情绪切换药丸按钮，点击即时切换
- 切换情绪时宠物外观/颜色/动效同步变化（如「发疯」→酸绿荧光加强，「破防」→脏紫泪眼）
- 情绪值进度条（纯视觉装饰，随交互增减）

### F3 — 触摸交互反馈动效
- **戳一戳**：点击宠物身体 → 弹簧阻尼抖动（`useFrame` + `lerp` 手写弹簧，0.12阻尼系数）
- **喂食**：点击喂食按钮 → 宠物嘴部张合动效 + 情绪值+10
- **发疯模式**：长按发疯按钮（>800ms）→ 宠物全身抽搐 + 颜色从酸绿跳红 + 全屏色差扫描特效，持续2秒后复位
- idle 状态：宠物缓慢呼吸膨胀（sin曲线scale变化）+ 眼皮半睁微颤

### F4 — 情绪贴纸生成与导出
- 底部「生成贴纸」按钮：将当前3D宠物+情绪状态渲染为 240×240 PNG
- 技术实现：Three.js `renderer.domElement.toDataURL('image/png')` 截帧
- 生成后弹出操作浮层：下载到本地 / 复制到剪贴板（`navigator.clipboard.write`）
- 贴纸自动打上情绪标签水印（如「摆烂中 🥀」，等宽字体）

### F5 — 贴纸导出面板
- 从主屏右滑进入
- 展示本次会话生成的所有情绪贴纸（2列网格）
- 每张贴纸卡片：缩略图 + 情绪标签 + 下载图标 + 复制图标
- 底部说明：「支持导出PNG / 复制到剪贴板，可直接发微信/小红书」
- 左滑或顶部返回箭头回到主屏

## 信息架构

```
主互动屏（默认）
├── 顶部状态栏：当前情绪文字标签
├── 主区域（78%）：3D宠物展示 + Bloom后处理
└── 底部HUD（22%）：
    ├── 情绪切换药丸（5种）
    ├── 情绪值进度条
    └── 交互按钮（戳一戳 / 喂食 / 发疯）

右滑 → 贴纸导出面板
├── 顶部：返回箭头 + 标题「我的情绪贴纸」
├── 「生成当前情绪贴纸 240×240」主操作按钮
├── 贴纸网格（2列，本次会话缓存）
└── 底部说明文字
```

**导航方式**：无持久 tabbar，右滑手势进出贴纸面板；全部交互靠触摸手势（点击/长按/滑动）

## 技术架构

- **框架**：React + React Three Fiber + @react-three/drei + @react-three/postprocessing
- **3D模型**：程序化几何体（默认）/ useGLTF 加载外部 .glb（可替换）
- **动画**：useFrame + ref驱动，手写lerp弹簧阻尼，无外部动画库依赖
- **后处理**：Bloom（荧光轮廓）+ ChromaticAberration（色差）
- **移动端性能**：frameloop="demand" 静止停帧；DPR上限1.5；pointer事件统一触摸/鼠标
- **贴纸导出**：renderer.domElement.toDataURL + Clipboard API

## 视觉风格

暗纯黑底，酸性荧光绿与脏紫主色，半透明果冻质感宠物，HUD浮层有细密噪点颗粒覆盖。字体选用等宽/工业风（Space Mono / Cubic11），不用圆体手写体。整体传达「神经质、不稳定、丑萌发疯」的视觉语言，在微信聊天框里高辨识度。
